# Vsedi 開発日記

このディレクトリには、Vsedi の開発でその日に行ったこと、決めたこと、残った課題を日付ごとに記録する。

## 目的

- 後から「いつ、なぜ、この判断をしたか」を追いやすくする
- Issue / PR / ADR だけでは見えにくい、その日の作業の流れを残す
- 次回の作業開始時に、直前までの状態を把握しやすくする

## ファイル名

日付ごとに次の形式で作成する。

```text
YYYY-MM-DD.md
```

例:

```text
2026-08-10.md
```

## 記録する内容

原則として次を簡潔に記録する。

- その日に行った作業
- 確定した設計判断
- 作成・更新した Issue / PR / ADR
- 実装・検証した内容
- 未解決事項や次に行うこと

## 方針

- 日記は設計仕様の正本にはしない
- 正式な設計判断は ADR、要件は `docs/development/requirements.md`、計画は `docs/development/roadmap.md`、実作業は Issue / PR を正本とする
- 日記には、それらへの参照と作業経緯を残す
- 秘密情報、credential、token、password 等は記録しない
- 後から事実関係を修正する必要がある場合は、履歴が分かる形で修正する
