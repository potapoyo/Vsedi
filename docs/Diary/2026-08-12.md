## M3実装 — ローカル保存の縦切り

- `git status --porcelain=v2 -z` を解析する変更一覧と、Rust正本の共有型を追加した。変更・削除・rename・未管理・競合と空白・日本語pathをテストで扱う。
- 未初期化projectでは、`.gitignore` / `Packages/.gitignore` の不足ruleをpreviewする。既存内容と改行形式は保持し、不足ruleだけを追記する。
- preview tokenが変化していない場合だけ `git init`、または `git add -A` / `git commit` を実行する。既存staged変更・競合・空変更・空メモは保存しない。
- 保存成功時にはcommit ID、時刻、file数を表示し、履歴とcommit詳細（変更file・text/binary/unavailable diff）を読み取れるようにした。
- `git add`後のcommit失敗および初期化後のignore書込失敗は、状態が変化した可能性をアプリerrorで明示する。
- ADR 0013へM3のindex、preview、初期化安全方針を記録した。
