# 2026-08-18

## 20:17 — Slint移植を優先しM4計画を保留

### 指示

- 現在の段階からSlintへの移植を進める方針を検討する。
- ここまでの判断を日記に記録し、M4の計画はいったん破棄する。

### 対応

- 現在の実装はTauri v2 + React + TypeScriptをUIに使用し、Git・診断・保存・履歴などの主要なサービスはRust側に分離されていることを確認した。
- SlintはRustと組み合わせたデスクトップUIとして利用でき、Project一覧、保存履歴、ファイルツリー、ログなどはSlintのListView / TableView / ScrollViewへ移植可能と判断した。
- 移植時はReact / TypeScript / Vite / Tailwind / shadcn/ui、Tauri command・plugin境界、Playwright / WDIOのUIテストを置き換える必要がある。一方、Rustのservice / git / model / error層は再利用を優先する。
- M4の実装計画 `docs/development/m4-plan.md` を削除した。
- M4安全復元のADR 0014は、将来の再計画時の参考記録として保持し、状態を「保留」に変更した。
- roadmap、M3計画、別マシン向け引き継ぎを、次の開発対象がSlint移植の試作であることに更新した。

### 結果

- M3のTauri / React版を現行基準として保持し、次はSlint移植の小さな試作でUI・Rust境界・ビルド・テスト方式を検証する。
- 安全な復元の実装計画はSlint移植の方向性が固まるまで再開しない。
- Slint移植はまだ検討段階であり、製品UIの全面移行やM4要件の変更は未実施。
